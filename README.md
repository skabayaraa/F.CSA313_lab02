Baseline p95 утга: Системийн хэвийн ажиллагааны суурь үзүүлэлтийг тодорхойлохдоо эхний шатны буюу 5 VU-ийн туршилтаас гарсан p95 = 313.31ms утгыг baseline болгон сонгож авсан.

Алдааны босго (Error Rate): Системийн чанарын шаардлагаар HTTP хүсэлтийн алдааны хувийг rate < 0.01 буюу хамгийн багаар тогтоож, хэрэглэгчийн туршлагад сөргөөр нөлөөлөх алдаа гарахыг хязгаарласан болно.
